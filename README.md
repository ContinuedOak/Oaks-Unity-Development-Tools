# Oaks-Unity-Development-Tools
Making Unity Development Faster, Easier, Cleaner and More Organised

## Contains
- Project Information (Window -> Oaks Tools -> Project Information)
> - Refresh Statistics
> - Development Time (Only starts after being installed, wont count time before installed)
> - PlayMode Time (Only starts after being installed, wont count time before installed)
> - Project File Size (How large the current project file size is)
> - Assets Breakdown
>> - Last Build Time and Size
>> - Total Assets
>> - Total Asset Size
>> - Break down of in order on what takes up the most storage and how much % it takes up

- Script Statistics (Window -> Oaks Tools -> Script Statistics)
(Completely Ignores any scripts that is in a folder named Editor)
> - Refresh Scripts and Refresh Runtime Buttons
> - Project Statistics
>> - Total Scripts
>> - Lines of Code
> - Runtime Monitoring
 
- Set Folder and Hierachy to Custom Colours
> - Set Hierachy Object Colour (Control-Shift-Q)
> - Reset Hierachy Object Colour (Control-Alt-Q)
> - > - Set Folder Colour (Control-Shift-M)
> - Reset Folder Colour (Control-Alt-M)
